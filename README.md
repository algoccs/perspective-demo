# Perspective Demo Project

Una aplicación de demostración interactiva diseñada para explorar, analizar y visualizar conjuntos de datos masivos en tiempo real utilizando la potencia de **Perspective**. Este repositorio sirve tanto de entorno experimental como de recurso educativo para estudiantes y desarrolladores interesados en la analítica interactiva y renderizado de flujos de datos.

---

## 🚀 Características Principales

- **Visualización Interactiva:** Tablas dinámicas, gráficos de dispersión, diagramas de líneas y mapas de calor interactivos incrustados directamente en la interfaz.
- **Transmisión de Datos en Tiempo Real:** Configuración optimizada para manejar actualizaciones constantes de flujos de información sin penalizar el rendimiento del navegador o la aplicación.
- **Arquitectura Ligera:** Construcción modular ideal para demostraciones en vivo, laboratorios educativos y prototipos rápidos.
- **Multilenguaje/Consumo Versátil:** Demostración de integraciones fluidas y enlaces de datos preparados para entornos web modernos.

---

## 🛠️ Requisitos Previos

Antes de clonar e instalar el proyecto, asegúrate de contar con los siguientes componentes en tu sistema:

- **Python** v3.9 o superior.
- **Node.js** v16.x o superior & **npm** (si se ejecutan componentes del frontend web).
- Un navegador moderno compatible con WebAssembly (Chrome, Edge, Firefox, Safari).
